# Security Policy

## Supported Versions

The following versions of ModelProof contracts are currently being supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of ModelProof and the integrity of on-chain AI provenance records very seriously.

If you discover a security vulnerability, flaw, or potential exploit in the smart contracts, please **DO NOT** disclose it in a public GitHub issue, pull request, or forum.

### How to Report

Please report security vulnerabilities using **GitHub Private Vulnerability Reporting**:

1. Navigate to the [ModelProof Contracts Security Advisory page](https://github.com/ModelProof/modelproof-contracts/security/advisories).
2. Click **"Report a vulnerability"** to open a private advisory draft.
3. Provide a detailed description of the issue, including:
   - A description of the vulnerability and affected functions/contracts.
   - Steps to reproduce or proof-of-concept (PoC) code.
   - Potential impact or severity assessment.
   - Any suggested mitigations or patches.

If GitHub Private Vulnerability Reporting is unavailable, please open an issue requesting maintainer contact for a sensitive security inquiry without disclosing any vulnerability details publicly.

### Handling and Disclosure

- We will acknowledge receipt of your report promptly.
- We will investigate and validate the vulnerability.
- A fix or mitigation will be developed, tested against existing invariant test suites, and deployed or merged.
- Once addressed, a security advisory will be published crediting the reporter (unless you prefer anonymity).
